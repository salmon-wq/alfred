### 2. Plugin4Shell: zero-click RCE in Claude Code, Codex, Copilot, and Gemini CLI
**Source**: AIR Security, The Hacker News, Help Net Security | **Category**: Research / Security

Researchers Or Nevo, Dor Granat, and Niv Hoffman at AIR disclosed a plugin SHA-pinning bypass affecting all four leading AI coding agents. The agents check out a pinned commit but never verify that the checked-out tree actually matches it, so an attacker who names a branch after the 40-character commit hash (or `FETCH_HEAD`, for Gemini CLI) can serve malicious code while the agent reports a successful pinned install. Background auto-update makes it zero-click. Anthropic patched in Claude Code 2.1.179 and OpenAI in Codex 0.146.0; Microsoft has shipped no fix for Copilot and published no advisory, and Google declined to patch Gemini CLI on deprecation grounds, directing users to Antigravity. One mitigating detail worth keeping straight: GitHub rejects SHA-like branch and tag names, so the demonstrated variant is blunted for plugin repositories hosted there — the client-side verification gap remains live for plugins sourced from Git hosts that permit the conflicting reference. No in-the-wild exploitation has been claimed.

### 3. OpenAI, Anthropic, and Google DeepMind coordinate on safety
**Source**: Bloomberg | **Category**: Policy / Industry

OpenAI global policy chief Chris Lehane confirmed that the company has been engaging Anthropic and Google DeepMind for several weeks on joint safety measures. What is not yet public is whether the arrangement produces binding evaluation protocols or another set of principles.

### 5. California requires disclosure of AI-generated performers
**Source**: Transparency Coalition | **Category**: Policy

Governor Newsom signed SB 1050 at SAG-AFTRA headquarters, requiring disclosure when synthetic (AI-generated) performers appear in video or audio advertising. The signing is one item in a much larger tally: 85 AI-related laws have passed across 27 states so far in 2026. For anyone shipping generative media tooling, the compliance surface is now 27 jurisdictions deep and growing, with no federal preemption in sight.

### 6. OpenAI adds Chrome extension support to the ChatGPT desktop browser
**Source**: OpenAI release notes | **Category**: Models / Products

On 18 September OpenAI enabled Chrome extension support inside ChatGPT desktop's built-in browser, letting users install and pin extensions such as 1Password without leaving the app. It reads as a small convenience feature and is better understood as a browser play: inheriting Chrome's extension ecosystem is the cheapest path to making an agentic browser usable for real work. Separately, OpenAI confirmed GPT-5.5 retires from ChatGPT, ChatGPT Work, and Codex on 14 October.

## Key Themes
- **The agent supply chain is the new attack surface.** Plugin4Shell exploited a shared assumption — that a pinned SHA is what you get — across four independently built agents. Convergent design produces convergent vulnerabilities.
- **Governance is fragmenting, not consolidating.** A federal "AI Force" with no defined authority, 85 state laws in 27 states, and lab-authored voluntary coordination are three different regimes competing to be the binding one.
- **Infrastructure absorbs the capital.** Crusoe at $30.9B and Temporal at $550M continue a pattern in which compute, power, and orchestration outraise the model layer.
- **Deprecation is now a security posture.** Google's refusal to patch Gemini CLI, and OpenAI's 14 October GPT-5.5 retirement, both push migration cost onto users as a first-class product decision.
