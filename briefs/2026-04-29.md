### 2. Anthropic Withholds Claude Mythos Over Cybersecurity Risk
**Source**: llm-stats.com / renovateqr.com | **Category**: Models / Policy

Following a data leak in March that confirmed the existence of Claude Mythos — reportedly a 10-trillion-parameter model — Anthropic announced it will not release the model publicly, citing cybersecurity risks. Access is restricted to select partners under the codename Project Glasswing. The decision marks the first time a major lab has explicitly withheld a frontier model on safety grounds rather than staging a delayed release.

The deal would integrate Cursor's 50 million–plus developer user base directly with Grok, creating a vertically integrated AI-to-IDE pipeline and intensifying the coding-assistant wars with Anthropic and GitHub Copilot.

**Source**: AI2Work | **Category**: Industry / Models
