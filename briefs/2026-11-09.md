### 3. Claude Code's "Don't ask again" option exposed thousands of secrets on public GitHub
**Source**: The Hacker News / iTnews (Apiiro research) | **Category**: Industry

Apiiro found that approving a shell command with "Yes, and don't ask again" writes the full command, credentials included, to `.claude/settings.local.json`, which many users then committed publicly. Reported figures vary by methodology, from 1,379 distinct secrets in 1,122 files to 2,539 secrets across 1,994 repos, including 379 database passwords and 23 AWS keys. Reports indicate a gitignore fix in Claude Code 2.0.54, but affected users should rotate credentials and purge the file from git history.
