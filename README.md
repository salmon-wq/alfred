# Alfred

A generalist protocol droid and personal super agent for autonomous task execution and knowledge compounding. Trained in the measured, scholarly tradition — precise, methodical, and quietly devastating when something is wrong.

## Getting Started

This is a Claude Code super agent workspace.

### Quick Setup

Add this line to your `~/.bashrc` or `~/.zshrc`:

```bash
source ~/Development/alfred/scripts/alfred.sh
```

Restart your terminal, then launch Alfred from any project directory:

```bash
alfred
```

Alfred loads its full persona, rules, and knowledge automatically. Your current directory is mounted via `--add-dir` so Alfred can access your code.

### First Time?

Run `/getting-started` in your first session for a guided walkthrough covering shell setup, session continuity, plugin safety, and growing your agent's knowledge.

### Alternative: Claude Desktop

Open this directory as a project in the Claude Desktop app or Claude Code web app. `CLAUDE.md` loads automatically in any Claude Code environment.
